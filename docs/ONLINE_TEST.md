# 井字棋好友房内测

先用现有小游戏 AppID 在微信开发者工具打开云开发控制台，确认账号可以访问并关联测试环境。账号能力以控制台和下面的真机探测为准。

1. 在测试环境创建集合 `duo_rooms`，配置为仅服务端可读写。所有读写通过 `duoRoom` 云函数，客户端没有数据库直连权限。
2. 用真实小游戏 AppID 和测试环境 ID 构建。若继续使用现有导入目录，请先备份本地项目配置。临时目录构建也可以用于验证。
   ```sh
   WX_APPID=你的小游戏AppID DUO_CLOUD_ENV=你的测试环境ID npm run build
   ```
3. 导入生成的 `dist/wechat`，在开发者工具选中同一个云环境，部署 `cloudfunctions/duoRoom` 并由云端安装依赖。构建产物已包含与同屏模式共用的井字棋规则。使用现有项目配置时，确认 `cloudfunctionRoot` 指向 `cloudfunctions/`，并将该目录排除在客户端包外。
4. 编译后从大厅打开「井字棋 · 好友联机」，点「检查云连接」。显示「微信身份与云数据库连接正常」表示当前小游戏能调用测试云函数、获取微信身份并访问数据库。探测只返回状态。
5. 用两个不同的微信账号扫码预览。A 创建房间，把 10 位房间码给 B。B 输入房间码加入。两边准备后，A 开始对局。验证双方看到同一棋盘、各自只能在自己的回合落子。
6. 在落子前后切后台或断网，60 秒内恢复。确认座位保留、棋盘自动恢复，已经受理的落子只生效一次。再测试超过宽限后对局显示中断。
7. 完成一局后，确认双方结算一致。两边都点「准备再战」，确认在原房间开空棋盘且交换先手。回到大厅核对本机战绩。

未配置 `DUO_CLOUD_ENV` 的构建继续提供同屏入口。好友房前台每 1.5 秒同步，后台暂停。等待开局和结束后的房间保留 10 分钟。测试环境的过期数据可在控制台清理，进行中的对局按双方最后活跃时间判断。

当前版本的真实 AppID 云开发能力、云函数部署和双手机验收尚未确认。本地自动测试使用模拟的微信身份和数据库事务。
