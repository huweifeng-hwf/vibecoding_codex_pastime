# 双人互动小游戏大全 · 一起玩

面向情侣和好友的同屏小游戏合集。目前可玩**双人同屏井字棋、五子棋，以及 2–4 人翻牌配对、飞行棋**，共用大厅、结算和本机战绩入口。

井字棋好友房可在配置云开发环境的微信构建中进行内测。好友房结算独立于本机战绩。当前尚未正式发布。

## 快速运行

游戏 Web 构建需要 Node.js ≥22。Android 打包另需 Capacitor、JDK 和 Android SDK。

```bash
npm run check
npm test
npm run build
npm run dev
```

浏览器版本输出到 `dist/web`，微信小游戏输出到 `dist/wechat`。预览服务默认端口 4173。取得 AppID 后使用 `WX_APPID=你的AppID npm run build`，再将 `dist/wechat` 导入微信开发者工具。默认 AppID 为不可上传的占位符。

## 游戏规则与记录

井字棋、五子棋、双人翻牌配对和双人飞行棋可在对局顶部切换并排或面对面布局。面对面时把手机平放，X／黑方／1 号玩家坐在手机底端，O／白方／2 号玩家坐在手机顶端。两端各有朝向自己的轮次、结算和操作按钮，棋盘与牌阵在换手时保持固定。飞行棋在当前玩家一端显示掷骰按钮和落点说明。切换布局会保留当前对局，偏好保存在本机。

**井字棋**：两人轮流点击，横、竖、斜向先连成三子获胜。从大厅开局由 X 先手，结算后再战交换先手，中途重开保留先手。未完成的对局不计战绩。战绩按当前设备的 X/O 座位记录，最佳为胜局中玩家自己的最少落子次数；不对应微信身份、不跨设备同步，清理数据可能丢失。

**五子棋**：13×13 棋盘，轻点空交叉点即可落子。从大厅开局由黑方先手，再战交换先手但保持执子颜色。横、竖、斜任一方向连成五子或以上即获胜，无禁手。满盘且无人获胜判平。未完成的对局不计战绩，重开沿用本局先手。完成局数、平局和黑白胜场单独保存在本机，可在战绩页切换游戏查看。

**翻牌配对**：先选 2、3 或 4 人，轮流在 4×4 牌阵上翻两张牌。配对成功拿下这一对并继续翻，失败则短暂停留后盖回并换人。配对最多的玩家获胜，最高分并列记平局。再来一局保留人数，先手顺延一位。完成局数、平局和各座位胜场按人数分别保存在本机。

**飞行棋快局**：选 2、3 或 4 人，每人 2 架飞机。掷到 2、4 或 6 可从机库起飞，也可按点数移动已起飞的飞机；走完掷 6 的一步可再掷一次。沿十字棋盘的公共航线顺时针飞一圈，再沿本色返航道进中央终点。落到本色星标时顺风跳 4 格，落到补给格可再掷一次，落到乱流格退两格。每步最多触发一个特殊格，跳格或退格的终点被己方占用时留在原特殊格。公共航线最终落点有对手时，将对方撞回机库；己方飞机不能叠放。骰面和大号点数在选飞机时保持可见。棋盘会标出 A、B 的最终落点，操作区会预告特殊格效果。直接点棋盘上的高亮飞机后，飞机沿航线逐格移动，顺风、乱流和撞机也有对应动画。无棋可走则换人。点数刚好才能进终点，先送回两架飞机的人获胜。再战保留人数并轮换先手，本机战绩按人数保存局数和座位胜场。

从大厅直接点游戏可用游客开局，点卡片上的「选玩家」可以为各座位选本机档案，或沿用该游戏和人数上次用过的阵容。对局中会显示档案昵称与座位，档案局结算时可以打开「本局记录」。

「本机战绩」有四个页签。座位统计继续累计旧版数据和新对局。逐局历史从升级后的首局开始，支持按游戏及人数筛选，详情包括日期、参赛者、先手、结果和本局数据。好友交手榜按游戏及人数展示同机胜场，至少两名档案玩家参与的对局计入榜单，同胜场并列。选两名好友可查看共同对局、各自胜场、平局及其他玩家获胜的次数。游客局同样记入历史。玩家档案和对局数据都保存在当前设备。大厅的「玩家档案」可以新建档案。点开档案可查看胜场、筛选本人的历史、用该玩家开局、编辑昵称或删除玩家。改名后历史显示新昵称。删除后，玩家从开局选择和榜单中移除，历史对局保留，可在「已删除」中恢复。沿用上次阵容时，已删除的座位改用游客。
