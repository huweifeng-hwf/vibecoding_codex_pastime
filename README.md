# 双人互动小游戏大全 · 一起玩

面向情侣和好友的微信小游戏合集。目前可玩**双人同屏井字棋、五子棋，以及 2–4 人翻牌配对、飞行棋**，共用大厅、结算和本机战绩入口。

井字棋好友房可在配置云开发环境的微信构建中进行内测。好友房结算独立于本机战绩。当前尚未正式发布。

## 快速运行

需要 Node.js ≥22，无第三方依赖。

```bash
npm run check
npm test
npm run build
npm run dev
```

浏览器版本输出到 `dist/web`，微信小游戏输出到 `dist/wechat`。预览服务默认端口 4173。取得 AppID 后使用 `WX_APPID=你的AppID npm run build`，再将 `dist/wechat` 导入微信开发者工具。默认 AppID 为不可上传的占位符。

## 游戏规则与记录

**井字棋**：两人轮流点击，横、竖、斜向先连成三子获胜。X 首局先手，再来一局交换先手；中途重开/退出不计战绩。战绩按当前设备的 X/O 座位记录，最佳为胜局中玩家自己的最少落子次数；不对应微信身份、不跨设备同步，清理数据可能丢失。

**五子棋**：13×13 棋盘，轻点空交叉点即可落子。黑方首局先手，再战交换先手但保持执子颜色。横、竖、斜任一方向连成五子或以上即获胜，无禁手。满盘且无人获胜判平。未完成的对局不计战绩，重开沿用本局先手。完成局数、平局和黑白胜场单独保存在本机，可在战绩页切换游戏查看。

**翻牌配对**：先选 2、3 或 4 人，轮流在 4×4 牌阵上翻两张牌。配对成功拿下这一对并继续翻，失败则短暂停留后盖回并换人。配对最多的玩家获胜，最高分并列记平局。再来一局保留人数，先手顺延一位。完成局数、平局和各座位胜场按人数分别保存在本机。

**飞行棋快局**：选 2、3 或 4 人，每人 2 架飞机。掷到 6 可起飞或移动已起飞的飞机，走完可再掷。掷骰后点高亮飞机或下方按钮，无棋可走则换人。沿外圈顺时针走一圈后进入自己的终点航道。落在公共航道上的对手飞机所在格会撞回对方，己方飞机不能叠放。终点须点数刚好，先送回两架飞机的人获胜。再战保留人数并轮换先手，本机战绩按人数保存局数和座位胜场。
