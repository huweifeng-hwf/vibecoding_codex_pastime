# vibecoding_codex_pastime

用于记录和实践 Vibe Coding 与 Codex 辅助开发的个人实验仓库，逐步积累有趣的小项目、原型和开发经验。

## 当前状态

仓库处于初始化阶段，目前仅包含项目说明文档，尚未确定技术栈，也未添加应用代码、依赖或自动化测试。

## 开发方式

1. 明确要实现的小功能及其预期效果。
2. 根据需求选择合适的技术栈，并补充安装和运行说明。
3. 以小步迭代的方式开发，每次完成后进行相应验证。
4. 将可复用的经验、设计取舍和使用方法记录到文档中。

## 运行与验证

当前没有需要安装的项目依赖，也没有可执行的启动、构建或测试命令。添加首个项目后，请在此补充：

- 所需运行时及版本。
- 依赖安装命令。
- 本地启动方式。
- 构建和测试命令。
- 必需的配置项及不含敏感信息的配置示例。

## 协作约定

- 开发前先阅读现有文档，保留已有工作。
- 提交说明应清楚描述本次变更的目的。
- 新增功能时同步更新相关使用说明。
- 不向仓库提交密钥、访问令牌、密码或包含敏感信息的本地配置。
- 在云环境中优先使用已有检出目录；仅在明确需要时创建额外工作树。
